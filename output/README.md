# Output

This directory contains raster outputs generated by GeoRaster Explorer.

Example outputs include:

- Compound hazard rasters
- Classified hazard maps
- Environmental change outputs
- Other GIS-compatible GeoTIFF products

Generated GeoTIFF files are excluded from Git tracking because they may be
large.

## Example Output

`Khagrachari_Compound_Hazard.tif`

This raster represents the classified compound hazard output generated from
the Khagrachhari landslide and flood hazard surfaces.
